{# Operator prose macro — 2–3 factual sentences built from DB facts. Each sentence is gated on the data that supports it. If a fact is missing for a given operator, the sentence is omitted (no fillers). Args: operator — {name, type} total_routes — int total_trips — int top_origins — list[str], origin cities ordered by trip count top_destinations — list[str], destination cities ordered by trip count countries_served — list[str] (display names) price_min — int RSD, may be None price_max — int RSD, may be None avg_price — int RSD, may be None #} {% macro operator_prose(operator, total_routes, total_trips, top_origins, top_destinations, countries_served, price_min, price_max, avg_price) %}

{% endmacro %}
