{# Floating Action Button macro. Three intent flavours, picked by the caller: intent="search" — opens the global search bottom-sheet (data-action="search-sheet") intent="scrolltop" — scrolls window to top (data-action="scroll-top") intent="filters" — opens a filters bottom-sheet (caller provides the sheet id via `target`) Hide-on-scroll behaviour is handled by mobile.js — it adds `.m-fab--hidden` when the user scrolls down and removes on scroll up. Usage: {% from '_partials/_fab.html' import fab %} {{ fab('search', aria_label=_('nav.search')) }} {{ fab('filters', target='filterSheet', aria_label=_('filters.open')) }} {{ fab('scrolltop', aria_label=_('a11y.scroll_top')) }} #} {% macro fab(intent='search', target='', aria_label='Search') %} {% endmacro %}
