# Roadmap — Transit Serbia

## Фазы развития

### Фаза 1: Foundation (март–май 2026)
**Цель:** Работающий сайт с базовыми данными и первые индексируемые страницы

- [x] Flask скелет + DuckDB схема
- [x] Страницы маршрутов (межгородские)
- [x] Страницы градского транспорта Белград
- [ ] Скрапер gsp.rs (линии GSP Белград)
- [ ] Скрапер busticket4.me (расписания)
- [ ] SEO: sitemap.xml + robots.txt
- [ ] Деплой на K8s (ArgoCD)
- [ ] Google Search Console подключение
- [ ] AdSense заявка

**KPI:** 500+ проиндексированных страниц, первые 1000 органических посетителей

### Фаза 2: Data & Growth (июнь–август 2026)
**Цель:** Полные данные, трафик растёт

- [ ] Скрапер srbvoz.rs (поезда)
- [ ] OSM интеграция (остановки с координатами)
- [ ] Все комбинации городских пар (500+ SEO страниц)
- [ ] Live данные GSP (если API доступен)
- [ ] Умами аналитика
- [ ] €100/мес AdSense

**KPI:** 5000 MAU, 100+ € AdSense

### Фаза 3: Monetization (сентябрь 2026+)
**Цель:** Стабильный доход

- [ ] busticket4.me партнёрство/affiliate
- [ ] Srbija Voz прямые ссылки
- [ ] Мобильная оптимизация
- [ ] Расширение: Черногория, Босния
- [ ] €300–600/мес

## Конкуренты

| Сайт | Сильные стороны | Слабые стороны |
|------|----------------|----------------|
| busticket4.me | Покупка билетов онлайн | Нет городского транспорта |
| srbvoz.rs | Официальный | Плохой UX, нет SEO |
| gsp.rs | Официальный | Плохой UX, нет мобильной |
| prevoz.org | Широкий охват | Устаревший дизайн |

**Наше преимущество:** Объединение городского + межгородского в одном месте + современный UX + SEO-оптимизация
