# Roadmap — Prevozni

## Цель

Рабочий сайт с реальными данными, задеплоенный на K8s, зарабатывающий через Google AdSense.

**Дедлайн:** 1 месяц (конец апреля 2026)

---

## Фаза 1: Фундамент (неделя 1)

**Цель:** Готовый план, дизайн, чистая структура проекта

- [x] Flask скелет + DuckDB схема
- [x] Все маршруты: межгородские + городской транспорт
- [x] Sitemap + robots.txt
- [x] Документация (план, данные, SEO, монетизация)
- [ ] Дизайн через uipro-cli
- [ ] Финальная структура страниц согласована

---

## Фаза 2: Данные (неделя 2)

**Цель:** Реальные расписания, полная база маршрутов

- [ ] Скрапер GSP Beograd (gsp.rs) — линии и остановки
- [ ] Скрапер межгородских автобусов (busticket4.me/lasta.rs)
- [ ] Скрапер Srbija Voz (srbvoz.rs)
- [ ] OSM интеграция — координаты остановок
- [ ] 50+ городских пар в базе
- [ ] Cron-скрипт ежедневного обновления

---

## Фаза 3: Продукт (неделя 3)

**Цель:** Сайт готов к публикации

- [ ] Интеграция дизайна uipro в Flask шаблоны
- [ ] Все страницы сверстаны
- [ ] Privacy Policy + About страницы
- [ ] Core Web Vitals оптимизация
- [ ] Mobile-first проверка

---

## Фаза 4: Деплой (неделя 4)

**Цель:** Сайт в продакшне, AdSense подан

- [ ] Выбор и регистрация домена
- [ ] Helm chart для K8s
- [ ] ArgoCD pipeline (деплой по тегу)
- [ ] Cloudflare настройка (CDN + SSL)
- [ ] Umami аналитика
- [ ] Google Search Console
- [ ] AdSense заявка

---

## Конкуренты

| Сайт | Что хорошо | Что плохо |
|------|-----------|-----------|
| busticket4.me | Покупка билетов | Нет городского транспорта, платный |
| srbvoz.rs | Официальный | Ужасный UX, нет SEO |
| gsp.rs | Официальный | Устаревший, только Белград |
| prevoz.org | Широкий охват | Старый дизайн |

**Наше преимущество:** Городской + межгородской в одном месте, современный UX, бесплатно, SEO-оптимизировано.
