## Что копируем

- **BusTicket4.me:** Чистый дизайн формы поиска (Откуда / Куда / Дата)
- **BusTicket4.me:** Schema.org BusReservation/BusTrip разметка
- **GSP:** Структуру данных по линиям (номер, маршрут, остановки)

## В чём мы лучше

1. **Единое место** — городской + межгородской + поезда одновременно
2. **SEO-first** — каждая пара городов = отдельная оптимизированная страница
3. **Мобильный UX** — приоритет с первого дня (70% трафика с телефонов)
4. **Скорость** — Flask + DuckDB = быстрая отдача, нет тяжёлых JS фреймворков
5. **Бесплатно** — нет комиссий, нет регистрации
6. **Современный дизайн** — не государственный портал 2012 года

## Главный вывод

Рынок технически не занят. Официальные сайты ужасны с точки зрения UX и SEO. BusTicket4.me хорош, но зарабатывает на продаже билетов — мы нишируемся на информации и AdSense. Прямой конкуренции по SEO практически нет.
