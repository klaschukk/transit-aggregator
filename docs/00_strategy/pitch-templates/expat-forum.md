# Expat forum / Reddit / Facebook group — helpful-reply pitch

**When to use:** you spotted a specific thread where a real person asks
about buses in Serbia ("how do I get from Belgrade to Niš?", "best way
to reach Užice by bus?"). The goal is a reply, not a signature spam —
the link is in the second sentence, the rest is actually helpful.

**Do not use on:** threads older than 30 days, threads the OP already
marked solved, or any forum that explicitly bans self-promo links.

**Tone:** like a friend who happens to run the site. First-person
singular. No "we" pluralis majestatis.

**Length:** 60–120 words.

---

> Hope that helps!

## Per-day cap

Max 5 helpful replies/day per forum to avoid pattern-flagging. Reddit
especially will shadow-ban on more. If the subreddit has a self-promo
rule, comment without the link and DM the user separately.

## Anti-spam checklist

- [ ] Personalized first line (not a generic "hey!")
- [ ] Named the actual operators on the route (proves I pulled real data)
- [ ] Included two niche tips that aren't on our site (added value)
- [ ] Disclosed it's my project
- [ ] Link goes to the specific `/voznja/{from}-do-{to}/` page, not homepage
- [ ] Comment reads the same with and without the link (still useful either way)
