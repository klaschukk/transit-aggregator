Единственный источник дохода — **Google AdSense**. Никакого affiliate, прямых сделок или партнёрств на начальном этапе.

## Условия роста трафика

1. **Программатические страницы** — каждая пара городов = отдельная SEO-страница
2. **Реальные данные** — полное расписание GSP + все межгородские маршруты
3. **Core Web Vitals** — быстрая загрузка = лучше ранжирование = больше трафика
4. **Мобильная оптимизация** — 70%+ сербских пользователей с мобильных

## Точка безубыточности

Хостинг montiko: ~€20/мес фиксированно.
**Безубыточность: ~3,000 MAU** → достижимо в месяц 3–4.

## AdSense — когда подавать заявку

- Минимум 20–30 реальных страниц с контентом
- Сайт работает на постоянном домене
- Есть Privacy Policy и About страница
- Рекомендуется: после первой индексации в Google Search Console
