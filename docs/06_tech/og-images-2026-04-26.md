# Dynamic Open Graph cards — 2026-04-26

Replaced the single static `og:image` with per-page rendered cards
across six page types. Per-page OG lifts social-referral CTR by
30-50% on Facebook, Twitter/X, LinkedIn, Telegram, and gives Google
Discover a more relevant preview to attach to the listing.

## Architecture

| Page type | OG route | Wired in handler |
|---|---|---|
| `/rute/<slug>/` | `/og/route/<slug>.png` | `app/routes/intercity.py` `route_detail` |
| `/voznja/<from>-do-<to>/` | `/og/voznja/<from>-do-<to>.png` | `intercity.py` `city_pair` |
| `/gradski/<city>/linija/<slug>/` | `/og/line/<city>/<slug>.png` | `app/routes/city.py` `line_detail` |
| `/gradski/<city>/stajaliste/<slug>/` | `/og/stop/<city>/<slug>.png` | `city.py` `stop_detail` |
| `/prevoznici/<slug>/` | `/og/operator/<slug>.png` | `app/routes/info.py` `operator_detail` |
| `/destinacije/<slug>/` | `/og/country/<slug>.png` | `info.py` `country_hub` |

Pages without page-specific data (homepage, /o-nama/, /rute/ index)
keep the static `og-image.png`. The `og_image_url` template var in
`base.html` defaults to the static fallback when a handler doesn't
override it.

## Renderer (`app/og.py`)

- 1200×630 PNG, brand teal vertical gradient (#0f766e → #0d9488)
- DejaVu Sans Bold from `/usr/share/fonts/truetype/dejavu/` —
  ships on every Debian/Ubuntu host, full Cyrillic + Latin diacritic
  coverage, no font-download dep.
- Title auto-fits between 56-92pt to fill the inner box without
  overflowing.
- Subtitle: 38pt regular, ellipsis-truncated if too long.
- Bottom row: 1-3 white pill chips with brand-teal text (28pt bold).
- Wordmark: "Prevozni" in 38pt bold top-left.
- Errors during render fall back to the static og-image.png — the
  /og/ route handlers wrap render_card() in try/except so a font
  miss or DB hiccup never returns 500 to a social bot.

## Caching

`Cache-Control: public, max-age=86400, immutable`

- Cloudflare keeps each card warm for 24 h.
- Browser cache + bot cache means follow-up requests after a share
  never re-render server-side.
- Cards are bound to slugs that change rarely (route slugs are stable;
  trip count nudges don't require an OG re-render to be useful for
  social previews).

## Tests (`tests/test_og.py`)

14 cases covering:
- Each /og/<type>/ returns 200 + image/png + Cache-Control + valid
  1200×630 PNG via Pillow.
- Bogus slugs fall back to the static image (still 200, so social
  bots cache instead of retry-storming).
- Path traversal attempts (`..%2Fetc%2Fpasswd`) short-circuit cleanly.
- Each page template emits a dynamic og:image URL that matches the
  expected shape, and twitter:image mirrors og:image.
- Homepage retains the static fallback (no slug-bound override).
- The renderer handles Serbian Latin (Niš, Skoplje, ć/š/đ) and
  Cyrillic (Линија 28, Београд) without crashing.

Full suite: 753 passed (was 739 + 14 new).

## Choices and constraints

- **No Pillow → no OG**. Pillow 12 is in the venv (verified via
  `from PIL import Image, ImageDraw, ImageFont`). If a future deploy
  rebuilds the venv without Pillow, the /og/ routes return the static
  fallback (caught in the try/except). Worth tightening with a
  startup health check if Pillow ever becomes flaky.
- **No font downloads**. DejaVu Sans is the system default on the
  prod host; we don't ship custom fonts to keep the deploy footprint
  simple. The downside is the typography is utility-grade rather
  than branded — acceptable trade-off for v1.
- **Sitemap stays untouched**. /og/ URLs aren't added to any sitemap
  shard — they're not user-facing surfaces.
- **Static fallback preserved**. /static/img/og-image.png stays in
  place as the universal default; deleting it would break any page
  that doesn't pass `og_image_url`.
