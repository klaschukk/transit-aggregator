## Почему нет рекламы на valocheck и flightpunctuality

Код AdSense стоит на обоих (adsbygoogle.js, тот же pub, ads.txt Authorized). Google не показывает рекламу,
потому что сайты не одобрены: «Low value content». Расстановка рекламы тут ничего не решает, решает контент.
Повторная проверка без изменений контента даст тот же отказ.

**valocheck** (отказ 12.09; с 10.10 один коммит — `1785dea`, бюджет Henrik только для браузеров и проверенных краулеров):
1. **436 из 720 URL в sitemap — страницы `/agents/a-vs-b/` на мусорных данных.** `app/static/data/agent_meta.json` от 31.07,
   ~17 игр на агента. Живая страница astra-vs-breach пишет «9.6-point win rate lead … is real signal, not noise». Это и тонкий
   шаблон, и неправда. Самый большой и самый дешёвый рычаг: noindex + убрать из sitemap, пока нет нормальной выборки.
2. Гайды по картам на 91 % одинаковые между картами, страницы про́-игроков на 81 %. Оставить в индексе только уникальные.
3. `/player/`: доля 503 упала с 67–99 % (до 10.10) до ~20–31 % (21–22.10). Для краулеров отдавать кэшированную страницу, а не 503.
4. В рабочей копии 29 незакоммиченных правок i18n от 10.10 — чужая работа, не трогать без владельца.

**flightpunctuality** (отказ 28.09, проект на паузе с 08.09; коммитов с 10.10 нет): 8 410 URL в sitemap
(5 104 маршрута, 3 196 рейсов, 66 авиакомпаний), ~100 слов текста на страницу, 80–86 % совпадения между соседями.
Реалистично: noindex почти всё, оставить 100–200 страниц с настоящим разбором (аэропорты, авиакомпании, топ-маршруты).
Это несколько дней работы под сайт, который сейчас на паузе. Рекомендация: сначала valocheck.

Где ставить рекламу после одобрения (максимум 2 на страницу, не в первом экране телефона):
- valocheck: игрок — после сводки статистики и между блоками матчей; агент/карта — после первого раздела; тир-лист — после первого тира.
- flightpunctuality: маршрут/рейс — после таблицы пунктуальности; авиакомпания — после сводки.

## prevozni: «напихать побольше» — не советую

- Уже стоят 2 ручных слота на длинных страницах (mid + bottom) с охранником в `base.html` (не в первом экране, ≥1,5 экрана между).
- Auto Ads уже включали 20.09: через день владелец сказал «сайтом невозможно пользоваться», доход вырос на ~€0,5. Откатили.
- Реклама даёт ~€1/мес (RPM ~€0,11). Основной доход — BusTicket4, ~€7,9/мес, и он требует, чтобы человек нажал «купить»,
  а не баннер. Больше баннеров — меньше кликов на BT4 и хуже Core Web Vitals. Скорее всего, суммарно в минус.
- Если владелец всё равно хочет: +1 слот только на самых длинных страницах (маршрут, линия), со скриншотами phone/tablet/desktop до выкладки.

## Bookaway: 1 642 клика за 7 дней, 0 конверсий

- Ссылки Bookaway есть только на ~400 страницах дальних направлений (`/voznja/<хаб>-do-<азия>/`, поиск), по одной на странице,
  прямо на трекер `bookaway2.go2cloud.org` (`rel="noopener nofollow sponsored"`).
- Заходов на эти страницы (люди + боты): 124 (20.10), 235 (21.10, из них 141 SemrushBot), 99 (22.10). Кликов у Bookaway
  22.10 было около 900. С наших страниц столько кликов быть не могло: кто-то бьёт по ссылке трекера напрямую. Скорее всего,
  краулеры, которые раньше собрали URL, или чекеры ссылок. 0 конверсий с этим согласуется.
- Наш учёт этих кликов не видел вообще: у кнопки класс `ai-route__cta`, его не было в селекторе трекера. Исправлено в `3e121c5`,
  теперь клики пишутся в `ba_clicks` с user-agent.
- Чем грозит: партнёрка видит тысячи кликов без продаж и может счесть трафик некачественным. Если отчёт Bookaway (часть B
  промпта) покажет, что клики не с наших aff_sub/стран, следующий шаг — пустить ссылку через свой `/go/`-редирект
  (Disallow в robots.txt, фильтр ботов по UA), чтобы краулеры не дёргали трекер напрямую.
