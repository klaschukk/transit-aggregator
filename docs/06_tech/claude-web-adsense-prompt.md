# Промт для Claude в браузере: настройка AdSense под prevozni.com

Кирилл вставляет текст ниже в Claude (расширение для Chrome), уже войдя в AdSense. Ответ агента (блок JSON) присылает в сессию
Claude Code или сам вписывает в `data/ads.local.json` и запускает `scripts/ship_local.sh --fast`.

Откуда список блоков: `config.py` → `ADSENSE_SLOTS` (ключи без идентификатора) и `data/ads.local.json.example`.

---

```text
Ты работаешь в моём аккаунте Google AdSense (я уже вошёл, вкладка открыта: https://adsense.google.com). Сайт: prevozni.com.
Интерфейс может быть на русском или английском, названия пунктов даю в обоих вариантах.

ЗАДАЧА
Создать 7 рекламных блоков для prevozni.com, проверить несколько настроек и вернуть мне отчёт в формате из раздела «ЧТО ВЕРНУТЬ».

ЧАСТЬ 1. Создать рекламные блоки
Меню «Объявления» (Ads) → вкладка «По рекламным блокам» (By ad unit) → «Медийные объявления» (Display ads).
Для каждого блока из списка:
  1. Название: ровно как в списке.
  2. Форма: как указано в списке (горизонтальная = Horizontal, квадратная = Square).
  3. Размер: «Адаптивный» (Responsive). Фиксированный размер не ставить.
  4. Нажать «Создать» (Create).
  5. В показанном коде найти data-ad-slot="..." и записать число в кавычках (обычно 10 цифр). Сам код никуда вставлять не нужно.
  6. Нажать «Готово» (Done) и перейти к следующему.

Список:
  prevozni_planner_hub          горизонтальная
  prevozni_planner_mid          квадратная
  prevozni_destinations_bottom  горизонтальная
  prevozni_city_index_bottom    горизонтальная
  prevozni_carriers_bottom      горизонтальная
  prevozni_stations_bottom      горизонтальная
  prevozni_about_bottom         горизонтальная

Если блок с таким названием уже есть, новый не создавай: открой существующий («Получить код» / Get code) и возьми его data-ad-slot.

ЧАСТЬ 2. Автоматические объявления должны быть выключены
«Объявления» (Ads) → вкладка «По сайтам» (By site) → строка prevozni.com → значок карандаша.
Запиши, что было включено до тебя: общий переключатель «Автоматические объявления» (Auto ads) и отдельно форматы
(закреплённые / Anchor, полноэкранные / Vignette, боковые / Side rail, объявления в странице / In-page).
Если что-то из этого включено, выключи и нажми «Применить к сайту» (Apply to site). На сайте реклама стоит только вручную, это моё решение.
Эксперименты и «оптимизацию» не запускай, даже если AdSense предлагает.

ЧАСТЬ 3. Только посмотреть и записать, ничего не менять
  a) «Сайты» (Sites): статус prevozni.com и статус файла ads.txt. Статусы остальных сайтов тоже запиши, но не трогай их.
  b) «Центр правил» (Policy center): есть ли нарушения или предупреждения по prevozni.com. Если есть, перепиши текст дословно.
  c) «Конфиденциальность и сообщения» (Privacy & messaging) → блок про европейские правила (GDPR): создано ли сообщение,
     опубликовано ли оно, для каких сайтов, и есть ли в нём кнопка отказа («Не соглашаться» / Do not consent).
  d) «Платежи» (Payments): есть ли красные или жёлтые плашки (подтверждение адреса, личности, приостановка платежей).
     Только текст плашки. Суммы, реквизиты и документы не открывай.
  e) «Защита бренда» (Brand safety) → «Блокировка» (Blocking controls) → prevozni.com → «Деликатные категории» (Sensitive categories):
     какие категории сейчас заблокированы.

ЗАПРЕЩЕНО
  - Вводить, менять или просматривать платёжные данные, налоговые формы, адрес, документы.
  - Удалять или переименовывать существующие рекламные блоки.
  - Менять что-либо у других сайтов аккаунта (valocheck.com, flightpunctuality.online и любые другие).
  - Включать автоматические объявления, закреплённые и полноэкранные форматы, эксперименты.
  - Менять настройки согласия (GDPR) и блокировок: по ним нужен только отчёт.
  - Отправлять сайт на повторную проверку.
Если AdSense просит пароль, код из SMS, подтверждение личности или показывает экран, которого нет в этой инструкции,
остановись и опиши, что видишь. Не угадывай и не выдумывай идентификаторы: если число не видно, так и напиши.

ЧТО ВЕРНУТЬ
1) Блок JSON ровно с такими ключами (значение = число из data-ad-slot, строкой; если блок создать не удалось, пустая строка):
{
  "ADSENSE_SLOT_PLANNER_HUB": "",
  "ADSENSE_SLOT_PLANNER_MID": "",
  "ADSENSE_SLOT_DESTINATIONS_BOTTOM": "",
  "ADSENSE_SLOT_CITY_INDEX_BOTTOM": "",
  "ADSENSE_SLOT_CARRIERS_BOTTOM": "",
  "ADSENSE_SLOT_STATIONS_BOTTOM": "",
  "ADSENSE_SLOT_ABOUT_BOTTOM": ""
}
2) Автоматические объявления: что было включено до тебя и что ты изменил.
3) По пунктам a–e из части 3: что увидел, коротко, с дословным текстом предупреждений.
4) Всё, что не получилось, и на каком шаге.
```
