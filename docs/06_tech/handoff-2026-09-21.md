## Уроки (не повторять)

- `#}` (Jinja) вместо `*/` в CSS-комментарии молча съел блок `:root` при минификации → после правки CSS проверять dist (`ship_local.sh` это делает).
- Root-файлы ломают ночные скрейперы (PermissionError). `find . -not -path './venv/*' -user root` должно быть пусто.
- Не долбить внешний API пачкой запросов подряд (Groq/Cloudflare 1010 банит IP бокса).
- Логи ночных запусков перекрываются (pregen идёт часами) — парсить только последнюю `Done:`.
- Не гонять тяжёлое (Lighthouse, массовые краулы) без нужды; массовую механику — субагентам на Haiku.
