# Шаблоны страниц

## 1. Главная страница (/)

**Цель:** Поисковая форма + навигация к популярным маршрутам

Блоки:
- Header: логотип + навигация
- Hero: большая форма поиска (Откуда / Куда / Дата)
- Популярные маршруты (карточки)
- Городской транспорт (ссылка на Белград)
- Footer: disclaimer + ссылки

**Ключевые слова:** "prevoz srbija", "red voznje", "autobus srbija"

---

## 2. Страница маршрута (/rute/{slug}/)

**Цель:** Полное расписание конкретного маршрута

Блоки:
- Breadcrumb
- H1: "Город А — Город Б"
- Метаинфо: расстояние, кол-во рейсов, цены
- Таблица рейсов: время отправления, прибытия, длительность, оператор
- Блок "О маршруте" (SEO текст)

Schema: `BusTrip` / `TrainTrip` для каждого рейса

---

## 3. SEO городская пара (/voznja/{from}-do-{to}/)

**Цель:** Захват длиннохвостовых запросов вида "beograd novi sad autobus"

Блоки:
- H1: "Beograd do Novi Sad — prevoz"
- Краткая сводка (сколько рейсов, от какой цены)
- Кнопка "Погледај све поласке"
- FAQ блок (когда первый автобус? сколько стоит? как долго едет?)
- AdSense блок

---

## 4. Городской транспорт (/gradski/{city}/)

**Цель:** Хаб для всех линий города

Блоки:
- H1: "Gradski prevoz Beograd"
- Сетка линий (карточки с номером и маршрутом)
- Поиск по номеру линии

---

## 5. Линия (/gradski/{city}/linija/{slug}/)

Блоки:
- Номер и название линии
- Список остановок в порядке следования
- Расписание (если есть)

---

## 6. Остановка (/gradski/{city}/stajaliste/{slug}/)

Блоки:
- Название остановки
- Список линий на этой остановке
- (Будущее) Ближайшие отправления в реальном времени
