# Монетизация

## Модели дохода

### 1. Google AdSense (основная)
- **Размещение:** Header, sidebar, между результатами, footer
- **CPM Сербия:** $0.8–1.5 (Tier 2/3 рынок)
- **Прогноз:**
  - 1000 MAU → ~€5/мес
  - 10K MAU → ~€50/мес
  - 70K MAU → ~€100/мес ← **первая цель**
  - 400K MAU → ~€600/мес ← **цель 18 мес**

### 2. BusTicket4.me Affiliate
- **Комиссия:** ~3–5% с продажи билета
- **Средний билет:** €8–15
- **Прибыль за конверсию:** ~€0.5–1.0
- **50 конверсий/мес → €25–50** — реалистично на 5K MAU
- Добавить UTM-ссылки на страницах маршрутов

### 3. Прямые размещения (долгосрок)
- Автобусные компании платят за featured listings
- Потенциал: €200–500/мес при 50K+ MAU
